Este template crea un catálogo de Unity Catalog respaldado por un bucket externo de S3 y requiere privilegios específicos de AWS tanto en Databricks como en AWS IAM.

* **Workspace de AWS.** Este template usa S3 e IAM; no aplica a workspaces de Azure ni de GCP. Confirma que el host de tu workspace sea `*.cloud.databricks.com`.
* **Unity Catalog habilitado en el workspace.** Ejecuta `databricks catalogs list --profile <PROFILE>` y comprueba que el comando se complete correctamente y que aparezca al menos un catálogo (por ejemplo, el catálogo predeterminado de tu workspace). Un error `not enabled` indica que el workspace no está asociado a un metastore de Unity Catalog.
* **Privilegios de metastore para crear credenciales y catálogos.** Necesitas `CREATE STORAGE CREDENTIAL`, `CREATE EXTERNAL LOCATION` y `CREATE_CATALOG` sobre el metastore. Si alguna llamada de la CLI en este template devuelve `PERMISSION_DENIED`, pide al administrador del metastore que te otorgue el privilegio que falta.
* **Un bucket de S3 y un rol de IAM en la misma región de AWS que tu workspace.** El bucket puede estar en otra cuenta de AWS: precisamente el acceso entre cuentas es lo que proporciona el rol de IAM de la credencial de almacenamiento. El template explica cómo apuntar una credencial de almacenamiento al rol de IAM; ya debes contar con permisos en AWS para crear el rol y la política.
