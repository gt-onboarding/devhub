Este template prepara un repositorio de Databricks para el trabajo con agentes: instala conocimiento de la plataforma Databricks en el agente de programación del usuario, configura el servidor MCP de DevHub Docs y escribe un `AGENTS.md` (con un `CLAUDE.md` enlazado simbólicamente) que fija los valores predeterminados del workspace que los agentes necesitan para actuar correctamente sobre este código base.

* **Un repositorio en el que incorporar al agente.** Ejecútalo desde la raíz del proyecto en el que trabajará el agente. Si el usuario aún no tiene un proyecto, ejecuta primero [Spin Up a Databricks App](/templates/spin-up-databricks-app) y vuelve aquí desde el directorio generado.
* **Un agente de programación instalado localmente.** El instalador de Databricks aitools detecta Cursor, Claude Code, Codex CLI, OpenCode, GitHub Copilot y Antigravity. La instalación del servidor MCP de DevHub mediante `npx add-mcp` funciona con ese mismo conjunto, además de VS Code.
* **`npx` disponible.** La instalación del MCP de DevHub se ejecuta mediante `npx add-mcp`, que viene con Node.js `18+`. Ejecútalo con `--yes` para que la instalación no sea interactiva cuando tu agente la lance en una shell sin interfaz.
* **Saber qué recursos de Databricks usará este repositorio.** Antes de escribir `AGENTS.md`, preguntarás al usuario qué CLI profile, URL del workspace, catálogo/schema de Unity Catalog, project/branch de Lakebase, Genie Agent y endpoint de Model Serving deben tomarse como valores predeterminados de este repositorio. No pasa nada por dejar campos en blanco con una marca `TODO:` si el usuario todavía no lo sabe.
