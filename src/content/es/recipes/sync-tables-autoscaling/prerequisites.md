Este template crea una tabla sincronizada que replica una tabla de Unity Catalog en Lakebase Postgres. Verifica que estas funcionalidades del workspace de Databricks estén habilitadas antes de comenzar.

* **Lakebase Autoscaling disponible.** Ejecuta `databricks postgres list-projects --profile <PROFILE>` y confirma que tu project de Autoscaling aparezca en la lista. Un error `not enabled` significa que Lakebase no está disponible para esta identidad.
* **CLI con soporte para tablas sincronizadas.** Las tablas sincronizadas en projects de Autoscaling se crean con `databricks postgres create-synced-table` (Beta). Ejecuta `databricks postgres create-synced-table --help` y confirma que el comando exista; si no, actualiza el CLI de Databricks. También puedes crear tablas sincronizadas desde la UI de Databricks (**Catalog** → tabla de origen → **Create synced table**).
* **Tabla de origen en Unity Catalog.** Ejecuta `databricks tables get <CATALOG>.<SCHEMA>.<SOURCE_TABLE> --profile <PROFILE>` y confirma que el origen exista; luego decide qué columna(s) funcionarán como clave primaria de la tabla sincronizada: se pasan como `primary_key_columns` en la especificación de creación. El origen no necesita tener declarada una restricción de clave primaria.
* **Change Data Feed habilitado en la tabla de origen (solo para el modo Triggered / Continuous).** Omite esta verificación si planeas usar el modo Snapshot. De lo contrario, ejecuta la sentencia `ALTER TABLE <catalog>.<schema>.<table> SET TBLPROPERTIES (delta.enableChangeDataFeed = true);` del Paso 1 en tu SQL warehouse.
