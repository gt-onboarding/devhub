Verifique se estes recursos do workspace do Databricks estão habilitados antes de começar. Se alguma verificação falhar, peça ao administrador do workspace que habilite o recurso.

* **Endpoints da Foundation Model API com governança do AI Gateway.** Os endpoints de modelos de fundação hospedados pelo Databricks já vêm pré-configurados com os recursos do AI Gateway (usage tracking, rate limits, guardrails). Confirme a disponibilidade listando os endpoints e verificando a configuração: `databricks serving-endpoints list --profile <PROFILE>` deve retornar pelo menos um endpoint de modelo de fundação `databricks-*`, e `databricks serving-endpoints get <endpoint-name> --profile <PROFILE> -o json | grep -q '"ai_gateway"' && echo ok` deve exibir `ok`. A disponibilidade dos endpoints varia conforme o workspace e a região.
