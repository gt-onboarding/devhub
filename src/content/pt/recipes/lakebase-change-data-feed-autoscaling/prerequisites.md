Verifique se estes recursos do workspace do Databricks estão habilitados antes de começar. O Lakebase Change Data Feed (CDF, anteriormente Lakehouse Sync) está em Public Preview e tem requisitos de workspace mais rígidos do que a maioria dos outros modelos.

* **Um workspace na AWS ou no Azure em uma região com Lakebase Autoscaling.** O Change Data Feed está disponível em Public Preview tanto na AWS (`*.cloud.databricks.com`) quanto no Azure (`*.azuredatabricks.net`). Um administrador do workspace precisa primeiro habilitar o preview do **Lakebase Change Data Feed** na página **Previews** do workspace.
* **Um projeto Lakebase Autoscaling com tabelas.** Execute `databricks postgres list-projects --profile <PROFILE>` e confirme se o seu projeto de Autoscaling aparece na lista. Um erro `not enabled` indica que o Lakebase não está disponível para essa identidade. Este modelo não cobre a criação de projetos — consulte [Criar um projeto Lakebase](/templates/lakebase-create-instance) caso precise de um.
* **Acesso ao Unity Catalog.** Execute `databricks catalogs list --profile <PROFILE>` e confirme se o catálogo e o schema de destino para os quais você quer replicar estão presentes. Você os selecionará ao habilitar o Change Data Feed.
