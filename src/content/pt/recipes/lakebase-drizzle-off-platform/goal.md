Ao concluir, você terá:

* Um pool de conexões baseado em Lakebase com refresh automático de token via callback de senha
* O Drizzle ORM inicializado com o seu schema e pronto para queries com tipagem segura
* Um script de migração que monta uma URL de conexão temporária com credenciais atualizadas do Lakebase
* Uma configuração funcional do Drizzle Kit para geração de schema e migrações
