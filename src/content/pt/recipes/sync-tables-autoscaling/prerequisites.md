Este modelo cria uma synced table que espelha uma tabela do Unity Catalog no Lakebase Postgres. Antes de começar, verifique se estes recursos do workspace Databricks estão habilitados.

* **Lakebase Autoscaling disponível.** Execute `databricks postgres list-projects --profile <PROFILE>` e confirme que seu projeto com Autoscaling aparece na lista. Um erro `not enabled` indica que o Lakebase não está disponível para essa identidade.
* **CLI com suporte a synced table.** Synced tables em projetos com Autoscaling são criadas com `databricks postgres create-synced-table` (Beta). Execute `databricks postgres create-synced-table --help` e confirme que o comando existe; se não existir, atualize o Databricks CLI. Você também pode criar synced tables pela UI do Databricks (**Catalog** → tabela de origem → **Create synced table**).
* **Tabela de origem no Unity Catalog.** Execute `databricks tables get <CATALOG>.<SCHEMA>.<SOURCE_TABLE> --profile <PROFILE>` e confirme que a origem existe; em seguida, defina qual(is) coluna(s) servirá(ão) como chave primária da synced table — você as informa em `primary_key_columns` na especificação de criação. A origem não precisa ter uma restrição de chave primária declarada.
* **Change Data Feed habilitado na tabela de origem (apenas para os modos Triggered / Continuous).** Ignore esta verificação se pretende usar o modo Snapshot. Caso contrário, execute a instrução `ALTER TABLE <catalog>.<schema>.<table> SET TBLPROPERTIES (delta.enableChangeDataFeed = true);` do Passo 1 no seu SQL warehouse.
