Este modelo deixa um repositório Databricks pronto para agentes: instala conhecimento da plataforma Databricks no agente de programação do usuário, configura o servidor MCP do DevHub Docs e escreve um `AGENTS.md` (com um `CLAUDE.md` vinculado por symlink) que fixa os padrões de workspace que os agentes precisam para agir corretamente nesta codebase.

* **Um repositório para integrar o agente.** Execute a partir da raiz do projeto em que o agente vai trabalhar. Se o usuário ainda não tiver um projeto, execute primeiro [Spin Up a Databricks App](/templates/spin-up-databricks-app) e volte aqui de dentro do diretório gerado.
* **Um agente de programação instalado localmente.** O instalador do Databricks aitools detecta Cursor, Claude Code, Codex CLI, OpenCode, GitHub Copilot e Antigravity. A instalação do servidor MCP do DevHub via `npx add-mcp` funciona com o mesmo conjunto, mais o VS Code.
* **`npx` disponível.** A instalação do MCP do DevHub é feita pelo `npx add-mcp` — que vem com o Node.js `18+`. Execute com `--yes` para que a instalação permaneça não interativa quando seu agente a rodar em um shell headless.
* **Saber quais recursos do Databricks este repositório vai usar.** Antes de escrever o `AGENTS.md`, pergunte ao usuário qual perfil da Databricks CLI, URL do workspace, catálogo/schema do Unity Catalog, projeto/branch do Lakebase, Genie Agent e endpoint de Model Serving devem ser tratados como padrão neste repositório. Não há problema em deixar campos em branco com um marcador `TODO:` se o usuário ainda não souber.
